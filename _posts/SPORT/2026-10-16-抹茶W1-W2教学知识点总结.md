# Molchanovs（抹茶）Wave 1 & Wave 2 教学知识点总结

> **用途**：教练授课讲义 / 学员复习材料
> **教材来源**：《自由潜水教程 Wave 1 v2.0》《自由潜水教程 Wave 2 v2.0》官方中文版
> **实战关联**：结合本人 2021 年 AIDA 学习及下潜实践（27m→41m）总结

## 〇、体系概览（开课必讲）

Molchanovs 体系分为 **Wave 1-4（开放水域）** 和 **Lap 1-4（泳池）** 两条线，理论与泳池要求相同，Lap 补完开放水域课可转 Wave。

| 级别 | 闭气要求 | 深度 | 核心内容 |
|---|---|---|---|
| W1/L1 | 1:30 | 12-20m | 基础理论、法兰左入门、救援入门 |
| W2/L2 | 2:30 | 24-30m | 自由落体、单蹼、进阶平压、正念 |
| W3/L3 | 3:30 | 34-40m | 残气量以下平压、Mouthfill、免手平压 |
| W4/L4 | — | 50m+ | 竞技训练、口填充精通 |

**课程结构四要素**（W1/W2 相同）：理论（在线考试 30 题答对 80%）→ 陆地 → 泳池 → 开放水域（仅 Wave）。

**竞赛项目缩写**（两个级别通用，考试必考）：
- STA 静态闭气 | DYN 动态有蹼 | DNF 动态无蹼
- CWT 恒重有蹼 | CWTB 恒重双蹼（**禁豚踢**）| CNF 恒重无蹼 | FIM 自由沉浸（攀绳，课程中穿双蹼）

**重要执行规则**：先双蹼达标才能尝试单蹼；所有技能用面镜完成（仅无蹼项目可用鼻夹）；报名先决条件为不间断游 200m。

## 一、Wave 1 知识点

### 1.1 物理学（第二章）

**压力与波义耳定律**
- 海平面 1 bar；**每下 10m 加 1 bar**（10m=2bar，20m=3bar，30m=4bar）
- 波义耳定律：恒温下气体体积与压力成反比 → 10m 体积 1/2、20m 1/3、30m 1/4
- 快速换算：深度(m) =（压力(bar) − 1）× 10；压力(bar) = 深度 ÷ 10 + 1
- 受影响的空腔：**中耳、鼻窦、面镜**（需主动平压）；肺是弹性腔不需平压；胃肠道不需平压
- 需平压空腔只有三个——这是 W1 最常考的判断题

**浮力与阿基米德定律**
- 浮力 = 排开液体的重量；正浮力（漂浮）/ 负浮力（下沉）/ 中性浮力（悬停）
- 浮力五因素：**深度、水质（海水要更多配重）、装备（湿衣厚度）、肺内气量（初学者每次吸饱）、身体成分**
- 深度影响浮力的机制（两条定律链式串联）：下潜 → 压力↑（波义耳定律）→ 湿衣/肺内气体体积↓ → 排开水的体积↓ → 浮力↓（阿基米德原理）
- 应用：上升最后约 5m 正浮力可停止踢蹼；下潜到负浮力区可进入自由落体（W2 核心铺垫）

**配重设置（安全重点）**
- 配重过重的危险：水平潜水中可能毫无察觉地迅速下沉，紧急情况极难自救
- **水面吐气测试**：握浮球深吐气→屏息松手→不应下沉（额头浮动可以）
- 泳池动态：中性浮力设在水下 **1m**；蹬壁滑行+一次划手测试调整

### 1.2 生理学（第三章）

**O₂ 与 CO₂ 的关系（核心概念）**
- 细胞呼吸：O₂ + 葡萄糖 → ATP 能量 + CO₂ + 水
- **呼吸欲望由 CO₂ 升高引起，不是 O₂ 消耗引起**——初学者最常见的认知错误
- CO₂ 升高 = 安全警报系统（高碳酸血症）；O₂ 过低才是真正的危险（低氧）

**哺乳动物潜水反射 MDR（必背）**

触发因素 4 个：①面部入水 ②闭气 ③压力增加 ④低温

生理变化 5 项：
1. **心动过缓**——心率下降，减少耗氧
2. **脾脏效应**——释放储存的红细胞，提高携氧能力
3. **末梢血管收缩**——四肢血液推向核心（也是长潜后腿沉、乳酸堆积的原因）
4. **血液转移**——肺血管扩张充血，弥补肺容积缩小，为深度潜水打基础
5. **中央血管舒张**——心脑肺血流增加

附带效应：浸入利尿（静水压+血液转移+低温→多尿）→ **全程补水很重要**（关联脱水与 DCI 风险，W2 展开）。

**短期 vs 长期适应**
- 短期 = MDR；长期 = 红细胞增多、低氧阈值降低、细胞用氧效率提高、呼吸系统增强、血管弹性增加
- 教学要点：CO₂ 耐受提升快（停训退化快、恢复也快）；低氧能力提升慢

### 1.3 放松与呼吸（第四章）——陆地课核心

**三段式呼吸流程**：
1. **准备阶段**：身体扫描 ≥2 分钟（头→脸→颈→肩→背→臂→手→胸→腹逐区放松）
2. **全呼吸（最终呼吸）**：腹式吸满 → 胸式补吸 → 锁喉"hhha"放松（举重前锁声门的动作，省能防漏气）
3. **恢复呼吸（Hook Breath）**：被动吐气 → "hope"式主动大口吸 → 对抗阻力吐一半 → 再吸满 → **至少重复 3 次**

**铁律：完成恢复呼吸，一次闭气才算结束。** 再短再浅的潜水也要做，练成潜意识习惯。

**可选：三次净化呼吸**（胸式，给 CO₂ 耐受低的学生建立自信）；长期目标是逐步减少到 0 次。

**过度换气（W1 最重要的安全章节）**
- 定义：呼吸量超过身体所需
- **它不会储存更多 O₂，只会排掉更多 CO₂** → 呼吸欲望被延迟 → 虚假舒适感 → 可能无预警直接 BO
- 症状：头晕、指尖刺痛、心率加快、欣快感、嘴角麻木、金属味
- 正确做法：放松 + 自然呼吸；安全长时间闭气的钥匙 = **放松能力 + CO₂ 耐受**

### 1.4 耳压平衡（第五章）——W1 最难技术章节

**解剖三结构**：咽鼓管（平时封闭，吞咽/打哈欠时开放）、中耳、鼻咽。

**两种技术对比**：

| | 阀式 Valsalva | 法兰左 Frenzel |
|---|---|---|
| 原理 | 用呼吸肌挤压肺内空气 | 用舌/喉部肌肉挤压口腔空气 |
| 优点 | 天生会，零学习成本 | 呼吸肌全程放松、省氧、深度下依然有效 |
| 缺点 | **深度越深越无效**（肺体积被压缩），强做危险 | 需要练习（约 1/4~1/3 的人天生会） |

**法兰左五步**：捏鼻 → 锁舌（T/K 音位顶上颚，或 P 音位挤唇颊）→ 关声门 → 提喉把气压入鼻 → 听到"噗"声 → 重复

法兰左失败两大原因：**声门漏气**（气被压回肺）或 **软腭紧张**（气进不了鼻腔）。

**平压训练器练习体系**（声门控制 → 软腭控制 → 喉舌控制 → 组合），重点练习：
- 软腭觉知：鼻呼吸↔嘴呼吸反复切换（实战验证有效，见第三部分）
- 气球练习：吹气球后控制气从鼻子"出-停-出-停"

**平压三原则**：**尽早**（水面就先平压，疼痛=已太晚，立即停止上浮）、**频繁**（理想在压力感出现前）、**放松**（脸颈紧张→咽鼓管关闭）。无法平压→抓绳停降，头向对侧倾斜再试，不行就上浮。

### 1.5 潜水技术（第六章：无蹼入门）

DNF 四步骤：出发（手引导）→ 划手（高肘、抱球轨迹、从头顶划到臀部）→ 蛙式向下蹬腿（小腿向下向内）→ 滑行。划手踢腿时**上半身保持水平**。

### 1.6 心理技术（第七章：可视化）

原理：大脑分不清真实与生动的想象。下潜前水面花 1-2 分钟"预演"完整一潜（鸭式入水→平压→踢蹼→转身→上升→恢复呼吸），细节和积极情绪越生动越有效。

### 1.7 潜在伤害（第八章）

**低氧链路**：缺氧早期症状（隧道视觉、温暖感、意识模糊）→ LMC 桑巴（BO 前的最后警告，运动皮层缺氧导致肌肉痉挛）→ BO 黑视

**BO 关键认知**：
- 低氧早期**反而感觉舒适愉悦**——最危险的陷阱
- 水下 BO 有喉痉挛保护（声带关闭防水入肺）——但不能依赖
- **出水后仍可能 BO**——所以出水后潜伴要持续看护、恢复呼吸要做满
- BO 后处理：纯氧 5-10 分钟（如有）、休息补水、**24 小时内禁潜**、复盘原因

**耳气压伤三度**（表 2）：

| 程度 | 表现 | 恢复周期 |
|---|---|---|
| 轻微 | 鼓膜发红、耳堵感 | 2 周内 |
| 中等 | 充血、剧痛、听力受损 | 2 周-2 个月 |
| 严重 | **鼓膜破裂**、眩晕、出血 | 2 个月以上，可能需手术 |

**内耳气压伤**：成因是**强行平压**！症状：持续眩晕、耳鸣、步态障碍，可致永久性听力损伤——"决不强行平压"的解剖学依据。

**其他**：逆向堵塞（上升时咽鼓管被黏液堵住→处理：抓绳停下、动下巴、吞咽、缓慢上升；感冒和药物潜水是主因）、面镜挤压（勿用无鼻袋泳镜下潜超过 1.5m）、鼻窦气压伤（面镜见血→头直立不后倾）。

### 1.8 安全与救援（第九章）——泳池/开放水域课核心

**水面休息时间规则**：**SI = p × t**（p=上一潜最大深度压力 bar 数向上取整，t=潜水时间）

| 案例 | 计算 | 休息时间 |
|---|---|---|
| 7m / 30s | 2 × 30s | 60s |
| 15m / 36s | 3 × 36s | 1分48秒 |
| 28m / 60s | 4 × 60s | 4分钟 |
| 35m / 80s | 5 × 80s | 6分40秒 |
| 62m / 140s | >60m | **24小时** |

**潜伴制度三种场景**：
- 静态：约定提示方式（每 15 秒报时；学员必须回应手势）；结束流程=扶壁→抬头→恢复呼吸
- 动态：潜伴在**上方**游动，穿蹼带呼吸管
- 深度：**会合深度 = 目标深度 1/3**，面对面沿绳上升，紧盯眼睛

**LMC 救援六步**：提示呼吸 → 支撑保护 → 摘面部装备 → 检查 → 当天停潜 → 复盘

**BO 救援三阶段**：
1. **水下**：背后接近 → 一手穿腋下、同手掌封嘴+两指固定面镜 → 另一手托后脑（**头不后仰**）→ 侧身踢蹼带出水面（负浮力区先卸配重）
2. **水面"吹+唤"**：摘装备 → 吹眼下方 + 呼唤名字（潜意识认得自己名字）→ **10-15 秒**未恢复→人工呼吸
3. **救援呼吸**：仰头抬颌捏鼻 → **5 次人工呼吸** → 无反应呼救 EMS / 无脉搏 CPR

### 1.9 装备（第十章）

- 湿衣：水导热是空气 **25 倍**；开孔内衬保暖最好但需润滑；保养=淡水冲洗+阴干
- 面镜：**低容积+软裙边**；仰面吸附测试
- 配重：3mm 湿衣约 3kg（20m 目标）/2kg（30m 目标）；5mm 约 5kg/4kg；马赛扣最可靠；戴髋不压膈
- 呼吸管：最简单湿式；**永远不要咬着呼吸管下潜**（BO 时水经呼吸管入肺）
- 脚蹼：泳池橡胶短蹼；开放水域软长蹼；材质效率 碳纤维 > 玻纤 > 热塑
- 安全绳（Lanyard）：**超过 20m / 大流 / 超出能见度必须用**；有蹼挂腕、FIM 挂踝、CNF 挂腰；**绝不连配重带**

## 二、Wave 2 知识点（聚焦 W1 之上的新增/深化）

### 2.1 自由潜水历史（第二章，考试新内容）

四阶段：采集食物（1 万年前，波罗的海贝丘）→ 应用（海女 2000 年史、波利尼西亚珍珠猎人日潜 35-40m、罗得岛 7m 以上打捞者分半宝藏）→ 知识发展 → 教育发展。

**必讲案例**：Stathis Chatzi（1913）为意大利军舰在 75-76m 寻锚，整潜 3 分钟——"两耳鼓膜受损但水下闭气远超水面"是绝佳的 MDR/血液转移教学素材。

### 2.2 进阶物理学（第三章）

**道尔顿定律**（分压定律）——理解浅水黑视的钥匙：
- 氧分压 = 总压 × 21%：水面 0.21 bar → 10m 0.42 → 20m 0.63
- 下潜时氧分压升高、氧气更易入血（**高氧血症**——深度平静感的来源）
- **上升最后 10m 压力降幅最大（减半），氧分压骤降 → 浅水黑视 SWB 高发区**
- 肺泡氧分压低于约 **0.1 bar** 可能 BO
- 实战理解：假设 -10m 时氧分压只剩 0.2 bar，到水面必然 BO——这就是安全员在最后 10m 戒护的原因

**亨利定律**——减压病的钥匙：下潜时氮气溶入血液组织，上升时释放慢得多 → **反复快速上升+短水面间隔 = 氮气泡累积** → DCI。

**深度配重新规**：中性浮力设 **10m**；目标深度大于 30m 时设 **目标深度的 1/3**（取较深者）。**配重过重在深度潜水中的容错率更低**——W2 红线。

### 2.3 进阶生理学（第四章）

**深度 vs 泳池差异（表 3，W2 最精华的理论）**：

| 维度 | 深度潜水 | 泳池潜水 |
|---|---|---|
| 舒适度 | 20m 时血浆溶氧 3 倍→高氧血症→深度平静感 | 只有 CO₂ 持续攀升 |
| 呼吸欲望 | 上升段 CO₂ 下降，**警告信号不足**（危险） | CO₂ 正常累积，欲望强烈 |
| 肌肉疲劳 | 只在浮力过渡区耗能，自由落体免费 | 全程持续供能 |
| 心率 | 45-70 BPM 完成大功率运动 | 同功率陆上运动 150+ BPM |

经典结论：**W2 的 30m CWT 实际只需约 45m 的踢蹼工作量**（10m 后自由落体 + 出水前 5m 免费上浮），比 60m DYN 更省力——帮学生破除"30m 很深"的心理障碍。

**残气量 RV 与血液转移**：RV ≈ TLC 的 1/4（成人男性 TLC 约 6L、RV 约 1.2L）→ 按波义耳定律 **35-40m 处肺被压缩到 RV**。血液转移（最多约 **1.5L** 血液涌入胸肺）使超越 RV 深度成为可能。W2 下 30m 时肺部可能短暂达到 RV 深度——**循序渐进是预防肺挤压的第一原则**。

**个体潜力七要素**：咽鼓管条件、心理稳定性、生理耐受、组织耗氧水平（耐力运动员未必强！）、肺活量与柔韧性、心肺血管弹性、技术有效性——教学上用于引导学生不攀比。

### 2.4 放松与呼吸进阶（第五章）

**三种呼吸模型**（进阶理论核心）：
1. 过度换气——休闲潜水禁用（Adam Stern 实验案例：只要超呼吸，30-40m 的容易深度也容易浅水 BO）
2. **潮气呼吸（推荐）**：约 500ml/次 × 15 次/分，只用横膈膜，负荷最小，W1-W3 最佳准备呼吸；深度放松可到"无意识闭气"状态
3. 呼吸不足（进阶，保留 CO₂，需大量训练）

**潮气呼吸与"吸一吐二"调息法的衔接（教学要点）**：
- 潮气呼吸 = 发呆/入睡时的自然呼吸（约 500ml × 15 次/分），核心是"**不控制、自动发生**"——只专注身体扫描，呼吸自己变慢变浅，不数秒数
- 学员常问的"吸 4 秒吐 8 秒"（1:2 调息，AIDA 常见教法）是刻意控制法，抹茶教材三分类中无此模型。判断安危的标准**不是吸吐比例，而是通气量（深度 × 频率）**：每口保持自然量（约 500ml，5 次/分 → 通气 2.5L/分 < 潮气 7.5L/分）→ 实际归入"呼吸不足"（安全但呼吸欲望来得早）；若慢呼吸时不自觉深吸 → 滑向"过度换气"（危险）
- **教学衔接顺序**：紧张学员先用 1:2（长吐气激活副交感神经）帮他沉下来 → 身体放松后撤掉节律控制 → 自然过渡为潮气呼吸 → 全呼吸 → 下潜。按抹茶考核口径，最终推荐答案始终是潮气呼吸
- 课堂金句："无论呼吸多快、多慢、多深或浅，氧饱和度都保持不变——没有任何呼吸可以增加体内的氧气量"

**陆地呼吸控制训练**：腹式吸→胸式吸→胸式呼→腹式呼完整循环，从 45 秒/循环练到 1 分钟以上——既是呼吸觉知训练也是拉伸。

**恢复呼吸 W2 细化**：出水第一吐**不要深吐**（防氧分压骤降）；严禁深而突然的吐气；出水前吐气（针对 packing/RV 以下深度）属 W3 技术，**W2 禁用**。

### 2.5 进阶耳压平衡（第六章）——W2 技术核心

**为什么必须放弃阀式**：10-15m 后肺体积太小，阀式需腹肌肋间肌强行推气，**可致肺损伤**。

**四种锁舌姿态（按需气量排序）**：

| 锁 | 口型 | 需气量 | 适用 |
|---|---|---|---|
| P 锁 | 用力说"P"，挤唇颊 | 最多 | 浅水 |
| T 锁 | 舌尖抵上齿后 | 较少 | 中浅层 |
| K 锁 | 舌中抵上腭 | 更少 | 较深 |
| SP 锁 | — | 最少 | W3（Mouthfill 先决） |

掌握全部锁舌是 W3 Mouthfill 的先决条件——**W2 学员要明白现在苦练的意义**。

**反向填积（石斑鱼叫）**：喉部把空气从肺"抽"入口腔，补充平压用气。步骤：关声门→喉舌下放形成口腔真空→开声门让气入嘴→关声门做法兰左。**严禁腹肌参与（腹部必须纹丝不动）**。

**免手平压（BTV）**：靠软腭和上咽部肌肉主动打开咽鼓管，最柔和但最难学；咽鼓管解剖分直型/狭窄 S 型/膝状 S 型三型，先天条件决定难度。

**真空原理（新概念）**：面镜或口腔形成低压会把鼻腔空气抽走——所以**所有气腔（面镜、口、鼻）都要定期平衡**，避免建立真空。

**平压原则强化**：永远在压力感之前平压；疼痛=立即停止；越深每米压差越小、平压间隔可以拉长；**平压较慢的那只耳朵决定下潜速度**。

### 2.6 深度潜水技术（第七章）——开放水域核心

**下潜十阶段（表 4，W2 技术主线）**：
1. 可视化 → 2. 放松 → 3. 入水（攀绳式/鸭式）→ 4. 规律平压 → 5. 流线姿态（头与身体一线、面向绳）→ 6. 正浮力区有力踢蹼 → 7. **自由落体**（停蹼、专注放松脸颈腹）→ 8. 转身（拇指朝上抓绳+前滚；**抬头转身拉伤喉部、后仰转身拉伤肺部——全程头与身体一线**）→ 9. 分段上升（负浮力区发力→正浮力区减力→最后 3-4m 停蹼）→ 10. 恢复呼吸+OK 手势

**踢蹼技术细节**：
- 振幅式双蹼：**膝关节角度始终 <45°**，前后力量均等
- 豚踢：前踢臀部后移、后踢骨盆前推
- 单蹼三要领：**锁膝 10-20° 微弯**（用臀发力，**忌股四头肌主动弯膝**）、控制臀部旋转、双脚伸直绷脚尖
- 双蹼时间公式：**潜水时间 ≈（深度 m × 2）+ 5 秒**（30m ≈ 65s）

**无蹼技术 8 项常见错误自查表**（表 5，教练水下纠错手册）：身体下倾→加配重；臀低→收脚跟时膝盖向下向后；抬头→头与身体一线；划臂只向侧→锁孔轨迹；无滑行→每个周期两个滑行段；动作过猛→平稳连贯。

### 2.7 心理技术：正念（第八章，W2 新增）

- 定义（Kabat-Zinn）：有目的地觉察当下，**不评判**
- 静态闭气应用：观察呼吸而不干扰→身体扫描→专注点任选（心跳/横膈膜感受/眼睑颜色/环境声/烛焰意象）
- **消极想法处理法**："我注意到我有'闭不到三分钟'的想法"——以旁观者视角不评判不跟随（"意识是匹野马"）
- 横膈膜抽动提前出现也不灰心：感受抽动间隙的放松，不对抗自然反应
- 深度应用：全程只想"此刻和下一步"，出水后微笑

**正念深化：理解、生活场景、瑜伽同源与练习规程**

**① 三个关键词拆解**：

| 关键词 | 含义 | 反面（常见误解） |
|---|---|---|
| 有目的 | 主动引导注意力到选定对象 | ≠ 发呆放空、≠ 什么都不想 |
| 当下 | 此刻的呼吸/心跳/声音/触感 | ≠ 复盘过去、≠ 计划未来（"还要撑多久"） |
| 不评判 | 只观察不贴标签："我注意到我有紧张" | ≠ "我又焦虑了，真没用"（这就是评判） |

- **为什么自由潜需要它**：闭气最大的敌人不是 CO₂ 而是**内心对话**——每句"还有多久""我行不行"都在加速耗氧（心率↑、肌张力↑）；正念是把注意力从"时间焦虑"搬到"当下体感"的工具
- **与 W1 可视化的关系（考试辨析点）**：可视化=预演未来，正念=安住当下——下潜前水面用可视化，入水后用正念，互补工具

**② 实际生活中的应用场景**：

| 场景 | 练法 | 与潜水的迁移 |
|---|---|---|
| 通勤/排队 | 烦躁转为观察：呼吸、脚踩地触感、环境声 | 水面等待=最好的练习场 |
| 跑步/运动 | 专注脚步触地与呼吸节律 | 动态闭气"专注每一划每一踢" |
| 睡前 | 身体扫描 | 就是 breathe-up 的日常版 |
| 情绪上头 | "我注意到我有愤怒/焦虑的想法"——旁观者法 | 静态闭气处理消极想法的原班工具 |
| 吃饭 | 正念饮食：味道、质地、饱腹信号 | 训练"觉察"这块肌肉 |

**③ 瑜伽中的正念场景（与自由潜同源技术，好用的教学衔接点）**：
- **体式（Asana）**：觉察身体对齐与"边缘感"（edge）——拉伸肋间肌时"感受而不对抗"，正是教材"感受抽动间隙的放松"
- **呼吸观察 vs 呼吸控制**：瑜伽调息法（Pranayama）多数是**控制**呼吸（如交替鼻孔）；W2 潮气呼吸是**观察**呼吸让它自然变慢——更接近正念本质，也是教材强调"自动发生"的原因
- **瑜伽 nidra（瑜伽睡眠）**：系统化引导的身体扫描，与 W1 身体扫描流程几乎一致
- **《瑜伽经》第一句**："瑜伽是心念波动的止息"——与"意识是匹野马"的禅宗故事完全同源
- **Kevala Kumbhaka（无意识闭气）**：教材提到的深度放松"暂时停止呼吸"，在瑜伽里是高级修行的标志——持续正念练习的深层结果
- 教学话术：直接告诉学生——"课程里的身体扫描、潮气呼吸、专注点，就是瑜伽传统的核心技术，只是换了潜水语境"

**④ 正确练习方式（实操规程）**——入门三要素：**姿势、对象、分心的回应**
1. 姿势：舒适稳定的坐姿或仰卧（不追求盘腿），脊柱自然直而不僵
2. 对象逐级：鼻孔气流/腹部起伏（5 分钟起步）→ 身体扫描（10-20 分钟）→ 环境声音 → 无选择觉察（进阶）
3. 分心的回应（核心技巧）：**走神 ≠ 失败**——注意到走神的那一秒恰恰是一次成功的觉察；温和标记（"思考""计划""回忆"）→ 轻轻带回呼吸，不骂自己；"野马"原则：不勒死它也不放跑它

**进阶阶梯（与闭气结合）**：
```
陆地正念呼吸（每天 10 分钟，固定时段，比偶尔 1 小时有效）
→ 陆地闭气中用专注点（心跳/横膈膜/烛焰）
→ 泳池静态（观察呼吸→身体扫描→专注点）
→ 深度潜水（"此刻和下一步"，出水微笑）
```

**四个常见错误**：追求"没有念头"（念头永远会来，练的是回应方式）；把练习当成绩（"今天质量好差"=评判本身）；用力"盯"呼吸（是温柔的觉察不是紧绷的监视）；只在绝对安静处练（进阶要在嘈杂中保持）。

**安全提示**：少数有创伤史者长时间冥想可能引发情绪波动——出现强烈不安就睁眼、感受脚踩地（接地）；闭气练习永远不在开车、站立、独自泡浴时做。

### 2.8 进阶气压伤（第九章）

新增重点——**肺气压伤（肺挤压 PBT）**：

- 机制：超越身体准备程度的深度→肺血管过度扩张破裂→血液入肺
- 高风险情形：未准备好快速下大深度、身体/精神不适仍下潜、深度下剧烈抽动或大幅动作、无法完全放松、错误使用填积
- 症状：胸口持续紧张、呼吸困难、咳粉红色泡沫（严重）
- 预防：循序渐进+接近深度时完全放松胸腹+**不使用教练没教过的技术（packing、FRC 属 W3）**+寒冷时停深度潜水
- 处理：立即停止一切潜水（包括戒护收绳）、轻柔呼吸控制咳嗽、避免剧烈移动保持低心率、吸氧、立即就医、至少休一周+医生许可

中耳/内耳/鼻窦/逆向堵塞/眩晕与 W1 框架一致，W2 强化了"**服药期间不潜水**"（药效在深度下会提前失效，平压问题在深处复发）和"两只耳朵不对称→变压性眩晕"的机制解释。

### 2.9 进阶安全与救援（第十章）

**BO 四大诱因分类（表 7，考试重点）**：

| 类别 | 要点 |
|---|---|
| 生理 | 体温异常（体温调节耗氧剧增）、**脱水**（血粘度升→血流慢→DCI+BO 双风险）、疲劳、药物 |
| 技术 | 超呼吸、低效技术、恢复呼吸错误、**咬呼吸管下潜**、packing（W2 禁用）、错误热身 |
| 心理 | 死盯数字目标、焦虑/过度兴奋、CO₂ 敏感性天生偏低者（这类人要**按计划深度执行而非等呼吸欲望**） |
| 物理 | 浅水黑视（最后 10m 氧分压降最快）、水面间隔不足 |

**减压病 DCI**：DCS（氮气逸出阻塞组织）+ AGE（肺撕裂气泡入动脉，主攻大脑→神经系统症状）。症状：异常疲劳、皮肤刺痛麻痹、关节痛、眩晕、视觉障碍。处理：100% 纯氧（30 分钟不缓解需减压舱）、补水、立即就医。

**潜伴制度升级**：会合深度 ≥ 目标 1/3（休闲通常不超 15m）；**出水后持续看护约 20 秒**（出水后 BO 窗口）；唇色发蓝要直接告知；LMC/BO 当天停潜。

**新增考核技能——无面镜自我救援（≤10m）**：CWT 下潜→转身 OK→面镜拉至颈部（不脱手）→可控上升（迷失方向则攀绳）→出水恢复呼吸。首次会晕头转向属正常，多练即安。

**15m 深度救援**：流程同 W1 三阶段，从 15m 执行（W1 是 6-10m）。

### 2.10 进阶装备（第十一章）

- 湿衣水温对照（2 小时潜水）：27-29°C→1-2mm；24-26°C→3mm；20-23°C→5mm；7-19°C→7mm；泳池静态 26-27°C→3-5mm

- 电脑表：实时深度/时间/水温/间隔 + **深度时间警报** + 日志

## 三、实战关联（结合个人经验的教学素材）

> 以下内容来自 2021 年 AIDA 学习实践，用于把教材理论"落地"，是课堂上最抓学生的部分。

### 3.1 法兰佐学习八阶段（自创教学工具）

教材说"约 30% 学生有平压困难，最终都能解决"——我自己的统计是**天生会法兰佐的约 1/4**。给挣扎的学生看这条路径，比说"多练"有用得多：

1. **原初之点**：完全感受不到舌根（对镜吐舌找舌根，小心下门牙划伤舌下）
2. 能抬起但**力量不够**（"用尽全力也顶不上去"=力量不足的典型感觉）
3. 力量够了但**方向错**（向前上方而非向后上方——看视频自查最有效）
4. 张嘴能通但软腭摩擦响
5. 闭嘴能通但**倒立不行**（矿坑实战：别人下深度，我头朝下攀绳反复练倒立法兰佐，不需要调息可以一直试）
6. 倒立能通（专项训练软腭：鼻嘴交替呼吸切换 + 气球"出-停-出-停"控制——与教材 EQ 训练器练习完全同源）
7. 灵活控制软腭，正倒一致、脸颊不鼓动（瑜伽倒立凳辅助）
8. 用法兰佐省鼻涕（师父水平，终极目标）

**软腭专项心得**：软腭无法直接感知，只能用"想象的力量"控制——鼻吐嘴吐鼻吸嘴吸反复切换直到灵活。

### 3.2 阀式的"死刑深度"——理论+实测

我第一阶段只能阀式下 12m：**到了深度之后肚子不管怎么用力都无法吐出气平压**——这就是失效深度的体感。

**失效深度公式**：失效深度(m) =（TLC ÷ RV − 1）× 10

- 我的例子：TLC 6L、RV 25% → 失效深度 =（6/1.5 − 1）× 10 = 30m（实测 30m 很难提气，吻合）
- **packing 提升 1L 的深度收益**：TLC 6→7L，可下深度从 30m 提到约 36.6m（+6.6m）——但 packing 属 W3 技术，W2 阶段讲原理不讲操作
- **横膈膜拉伸 RV 降 5%（25%→20%）**：可下深度直接 30m→40m（+10m）——**柔韧性训练的性价比远高于 packing**，这就是 Base 训练拼命拉伸肋间肌和横膈膜的原因

### 3.3 浅水黑视的算术课（道尔顿定律应用）

给学生算这笔账最直观：
- 水面氧分压 0.21 bar，下潜中不降反升（10m=0.42）→ **下降过程绝对安全**
- 上升中：-10m 处如果氧分压只剩 0.2 bar，到水面压力减半 → 0.1 bar = **BO 阈值**
- 所以：安全员在最后 10m 戒护；上升最后阶段绝不吐气；出水第一吐不要太深；恢复呼吸对抗阻力吐一半的原理（维持肺压促氧入血）

### 3.4 血液转移的"橘子比喻"

肺泡是橘子：果肉是肺泡里的空气，果皮是包裹气袋的血管。越深果肉越小，但果皮膨胀起来补偿体积损失——血液转移让 35-40m 以下的世界成为可能。搭配 Stathis Chatzi 1913 年 75m 寻锚案例食用更佳。

### 3.5 水面间隔规则：Molchanovs vs AIDA 对比（我两套都教）

| 体系 | 规则 |
|---|---|
| Molchanovs | SI = p × t（p 向上取整）；>60m 单次/24h |
| AIDA | ≤30m：水面时间 = 2 × 潜水时间；30-55m：深度(m) ÷ 5 分钟；>55m：24h |

两套都教，让学生理解**保守原则一致、具体数字是不同组织的安全余量**。

跨体系间隔（AIDA 经验，实用）：自潜后 12h 内不水肺；一次水肺后 12h 不自潜、多次水肺后 24h；大深度（55m+）/连续多日潜水/单日长时间渔猎后 24h 再坐飞机。

### 3.6 恢复呼吸 = 肌肉记忆，不是判断

LMC 发生时人无法冷静思考，**只能靠潜意识自动完成**——所以每次出水（哪怕 5m 热身潜）都必须做满恢复呼吸，练成条件反射。这是"为什么规矩这么死板"的最好回答。

### 3.7 湿衣过紧的亲身教训

第一次穿铁三胶衣下潜，太紧导致**无法完成有效全呼吸**——直接印证教材"湿衣不应限制呼吸"和 W2"湿衣过紧影响放松"。买湿衣必须穿好做一次完整全呼吸测试。

### 3.8 教学素材库（症状对照速查）

- **SpO₂ 参考值**：正常 96-98%；<86% 严重缺氧（类高反）；45-50% BO
- **超呼吸 vs 缺氧症状区分**：欣快+末梢刺痛+嘴角麻木+金属味=超呼吸（立刻停）；温暖感+隧道视觉+"潜水突然变容易"=缺氧前兆（立即上浮）
- **"潜水突然变容易"是最阴险的 BO 前兆**——大脑缺氧反而产生愉悦感
- 波尔效应一句话版：CO₂ 太低→血偏碱→血红蛋白抱氧更紧→氧送不到组织——超呼吸的危害闭环
- 鼻窦保健清单（预防鼻窦气压伤）：不吹空调、减少乳制品/小麦、多喝水、蒸汽吸入、Neti 盐水洗鼻、患侧朝上睡姿

## 四、安全红线（两个级别合并教学，逐条签字确认）

1. **绝不独自潜水**（包括脸浸水盆独自练闭气）——独自水面 BO 不会自行恢复
2. **绝不咬呼吸管下潜**
3. **决不强行平压**——内耳气压伤可致永久听力损伤
4. **切勿过度换气**
5. 耳痛/平压失败 = **立即停止下潜上浮**；下潜速度由较慢的那只耳朵决定
6. 感冒、鼻塞、耳/咽喉/支气管发炎、**服药期间**不潜水
7. 勿从面镜吸气；无鼻袋泳镜不超过 1.5m
8. 下潜前取出呼吸管；出水必须做满恢复呼吸
9. 遵守水面间隔（SI = p × t）；>60m 单次/24h
10. BO/LMC 当天停潜；**BO 后 24h 禁潜**；肺气压伤至少休一周+医生许可
11. 配重保守：中性浮力不浅于 10m；每次换环境/装备重新做中性测试
12. Lanyard：>20m/大流/能见度外必戴；绝不连配重带
13. W2 禁用 packing/FRC/出水前吐气（W3 技术）
14. 上升最后阶段不吐气；出水不突然深吐
15. 寒冷时停止深度潜水；深度下不做剧烈动作
16. 不死盯数字目标，按身体当天的状态做决定
17. 救援铁律：吹+唤 10-15 秒无反应→人工呼吸；无脉搏→CPR
18. 循序渐进是贯穿一切的总纲——舒适了再加深

### 6.1 专题一：减压病——为什么氮爱囤积在脂肪里

**基本链条（亨利定律）**：下潜时氮分压升高 → 氮气持续溶入血液和组织；上升过快 → 氮气来不及经肺排出 → 以气泡形式析出（可乐开瓶效应）→ 阻塞组织/血管。

**氮为什么偏爱脂肪**：
- 氮是脂溶性气体，**在脂肪组织中的溶解度约为血液的 5 倍**——脂肪越多，能"装"的氮越多
- 脂肪组织血流灌注差 + 溶解度高 → 属于**慢组织**（Haldane 舱室理论中半饱和时间最长的舱室以小时计，现代模型可达数百分钟）→ **吸得慢、排得更慢**
- 临床对应：神经纤维的髓鞘富含脂质（神经系统症状高发）、肥胖潜水员风险更高、出水数小时后才发作的**延迟性减压病**（慢组织还在慢慢吐泡）
- 延伸：深潜技术潜水用氦气替代氮气，正是因为氦在脂肪中溶解率只有氮的约 40%、扩散速率是氮的 2.5 倍——"囤得少、跑得快"

**分型**（结合 AIDA 实战总结）：
- **DCS I 型（组织型）**：氮气从组织逸出形成气泡→关节/肌肉疼痛、皮肤痒纹斑点
- **DCS II 型（神经/系统型）**：累及神经系统、前庭（眩晕）、肺（气哽）
- **AGE（动脉气体栓塞）**：肺气压伤→气泡直接入动脉→大脑首当其冲→以神经系统症状为主；卵圆孔未闭（PFO）会使静脉气泡绕入动脉

**处理**：停止潜水减少活动最好平卧 → 100% 纯氧 → 补水约 1L（不给食物）→ 送医（30 分钟吸氧不缓解需减压舱）→ 24h 内不飞行。

**自由潜为什么会得**（W2 教材原文）：单次自由潜吸氮量小，但**反复快速上升 + 短水面间隔**会累积——这就是水面间隔规则（SI=p×t）存在的意义。

### 6.2 专题二：水肺五米安全停留的原理

**根本差异**：水肺在高压下**持续呼吸压缩空气**（氮源源不断压入体内）；自由潜只有水面一口氮气。所以水肺必须做减压程序，自由潜只需水面间隔。

**五米停留 3-5 分钟的三重逻辑**：
1. **最后 5m 是相对压降最大的区间**：5m 处 1.5 bar → 水面 1 bar，压力降 1/3 到 1/2 量级（越接近水面每米相对变化越大）——气泡恰好在最后这段膨胀最猛（波义耳+道尔顿，与自由潜浅水黑视是同一个物理）
2. **停留 = 在气泡最危险膨胀之前"踩刹车"**：环境压力仍把已形成的微气泡压着，同时血液把组织里的氮运到肺部排出（每分钟仅几毫升，别指望排空，但足以让"静默气泡"不至于合并成致病气泡）
3. **给微气泡时间经肺泡滤过清除**，降低亚临床气泡负荷

**概念区分**：
- **安全停留**（预防性，5m×3-5min，所有较深或接近无减压极限的潜都建议做）
- **减压停留**（越过无减压极限后的**强制义务**，漏做=DCS 高危）
- 上升全程速率 ≤9-18m/min；技术潜水的减压站会按深度分层，最浅站（6m）用纯氧——衔接专题四

### 6.3 专题三：BO 之后为什么吸纯氧

**氧债（O₂ Debt）概念**：BO 意味着组织（尤其是大脑）已经缺氧；即使恢复意识和自主呼吸，体内总氧债仍很高——**出水后仍可能二次 BO** 的原因。

**纯氧的机制**：
- 吸空气时肺泡氧分压约 0.21 bar；吸纯氧升至约 **1.0 bar** → 肺泡→血液的扩散**梯度拉到最大** → 血氧快速回升 → **缩短大脑缺氧的时间窗口**，把"还债"速度提到最快
- W1 教材规定：BO 后如有条件，**纯氧 5-10 分钟**
- DCS 场景纯氧还多两层作用（**氧气窗原理**）：①吸入气中氮分压≈0 → 组织与肺泡之间的氮分压梯度最大 → **加速排氮**；②氧气会被代谢消耗、不在组织中蓄积张力，给惰性气体排出"腾位置"，并帮助气泡缩小

**注意**：给氧是现场急救不是治疗终结，BO/DCS 均需就医评估。

### 6.4 专题四：高氧血症的危害与纯氧的应用

**先分清两个"高氧"**：
- **自由潜的深度高氧血症**（W2 教材）：下潜中氧分压随深度升高（20m=0.63 bar）、血浆溶氧增至约 3 倍、抑制大脑活跃度——这就是"深度平静感"的来源。单次暴露时间短、30m 内远低于中毒阈值，**本身不危险**；真正的危险是上升时的**反向骤降**（浅水黑视）
- **氧中毒（Oxygen Toxicity）**：分压 × 时间超限后的真伤害，分两型：
  - **中枢神经型**（短时高分压，水中致命）：风险 >1.4 bar 显著上升、1.6 bar 为绝对红线。前兆：面部肌肉抽搐/刺痛、耳鸣、恶心、视野狭窄、烦躁 → 全身痉挛；**水下痉挛=失去呼吸道=溺亡**
  - **肺型**（长时间累积暴露）：气道刺激、胸骨后疼痛、肺组织损伤（用 OTU 单位累积计算）

**高氧的第三种效应——吸收性肺不张（肺泡坍缩）**：
- 机制：氮气几乎不溶于血液，平时在肺泡里充当**"支架"**（占吸入气 79%，进得慢出得也慢，把肺泡"撑"着）；吸入高浓度氧（FiO₂ > 0.5，纯氧最甚）后氮气被洗出、氧取而代之，而氧会被血液快速吸收 → 肺泡进行性缩小直至塌陷——**不是氧"烧坏"肺泡，而是氮支架被撤走、气体被抽空**
- 症状：塌陷区形成右向左分流，血液流经无通气肺泡无法携氧 → **血氧反而下降（"越吸氧越缺氧"的悖论）**，伴咳嗽、呼吸困难、肺活量下降
- 发生条件：需要**较长时间**的高浓度氧暴露——全麻插管吸纯氧者发生率高达 75-90%，是术后呼吸并发症主因
- 潜水场景对照：自由潜的深度高氧仅数分钟且 30m 内氧分压 ≤0.63 bar → **不会**吸收性肺不张；急救面罩给氧、技术潜水 6m 纯氧减压站都是分钟级 → 风险可忽略；真正受此困扰的是长时间纯氧治疗的临床患者和军用纯氧呼吸器潜水员
- 概念辨析（教学易混点）：自由潜下潜中肺泡"变小"是**波义耳压缩**（外面压扁），靠血液转移 + 肺表面活性物质保护防止塌陷（W2 教材原文）；吸收性肺不张是**气体被吸走**（里面抽空）——一个被压、一个被抽，机制完全不同

**算一笔账（MSD 数据）**：吸纯氧下潜到 **4m** 就达到 1.4 bar 中毒阈值 → **水下呼吸纯氧=玩命**。

**行业红线**：休闲潜水工作深度氧分压 ≤1.4 bar；技术潜水减压停留短暂放宽至 ≤1.6 bar——这正是技术潜水把纯氧减压站设在 **6m**（1.6 bar）的原因。

**纯氧的合法应用场景**：
1. **急救给氧**：BO / DCS / AGE 现场第一处置
2. **技术潜水减压气**：6m 浅站吸纯氧，用氧气窗极限加速排氮
3. **高压氧舱治疗**：2-3 ata 下间歇吸纯氧（约 60-90 分钟+空气休息段），靠"间歇暴露+严格时程+医疗监护"把神经型氧中毒率压到约十万分之七
4. **军用密闭纯氧呼吸器**：仅限极浅深度使用

**教学金句**：治疗时纯氧是药，深潜时纯氧是毒——**剂量（分压 × 时间）决定一切**。

### 6.5 跨体系间隔规则（衔接实战）

- 自潜后 **12h** 内不水肺；一次水肺后 **12h** 不自潜、多次水肺后 **24h** 再自潜
- 大深度（55m+）/连续多日潜水/单日长时间渔猎后，**24h** 后再坐飞机
- 机理：水肺潜水后体内仍有残余氮，紧接着的自由潜的压力波动会促发气泡形成——连续自由潜会把已产生的气泡压缩到足以通过肺屏障进入动脉（AIDA 坚持保守间隔的原因）

### 6.6 专题补充：多补水的原理

**潜水员为什么比常人更容易脱水（失水五途径）**：
1. **浸入利尿**（MDR 的副产品）：静水压 + 血液转移 + 低温 → 身体误判"中央血容量过多" → 肾脏加速排水 → 下水没多久就想尿（W1 教材 MDR 章节）
2. **出汗**：湿衣保温 + 水面等待时阳光暴晒
3. **呼吸失水**：长时间用嘴/呼吸管呼吸；水肺的压缩空气极为干燥（气瓶内空气已除湿防腐蚀），气道持续被"抽干"
4. **肾脏排酸**：闭气积累的 CO₂/乳酸等酸性代谢物经肾脏排出，带走大量水分
5. **低温利尿**：冷水刺激加剧情景 1

**脱水的四重危险**：
1. **血液变粘稠** → 心脏负荷增加、血流变慢 → 氧气运输效率下降 → 更早疲劳、横膈膜抽动提前、抽筋
2. **血流慢 + 组织灌注差 → 排氮效率下降 → 氮滞留** → DCI 风险升高（脱水是 W2 教材 BO 四大诱因和 DCS 风险因素的共同条目）
3. **黏液变稠** → 咽鼓管/鼻窦堵塞恶化 → **平压更困难**（脱水与鼻窦阻塞互为恶性循环）
4. 症状对照（实战总结）：痉挛、疲劳、隔膜早抽、鼻窦阻塞、DCI——出现两条以上先想想今天喝没喝水

**BO 后 / DCS 后补水的机理（急救场景）**：
- 核心逻辑：水是血液循环的载体，而**还氧债和排氮都完全依赖血液循环**——脱水让血变稠、灌注变慢，补水就是把运输系统重新提速
- **BO 后补水的三条原因**：①还氧债需要满速运转的运输系统（血稠→血流慢→大脑还债慢）；②脱水本身就是 BO 的生理诱因之一（W2 四大诱因），补水=纠正诱因；③闭气积累的 CO₂/乳酸经肾排出消耗水（肾脏排酸失水），脑缺氧后的修复代谢也需要正常水合——W1 教材把"纯氧、休息、多喝水、营养食物"并列为 BO 后标准护理
- **DCS 后补水的三条原因**：①排氮的唯一通道是被血液带走→经肺呼出，脱水→灌注差→排氮慢→气泡滞留更久→持续损伤（"浓稠血液引起氮滞留"的机理）；②DCS 本身会漏液——气泡损伤血管内皮→毛细血管渗漏→血浆漏入组织间隙→有效循环血量下降（重度可致低血容量休克），潜水已脱一层、病又漏一层，不补即恶性循环；③送医前现场能做的治疗就三件事：纯氧、平卧、补水——水合状态直接决定减压舱治疗时的灌注基础
- 急救细节：经口给水前提是**意识完全清醒**；DCS 急救"给约 1L 水、不给食物"——不给食物是防病情恶化需医疗处置或意识改变时呕吐误吸

**电解质失衡警示（脱水的高频伴生问题）**：大量出汗和浸入利尿丢的不只是水，还有钠、钾、镁——**只灌纯水会稀释血钠（低钠血症风险）**。识别：补了水仍抽筋不止、心悸/心律不齐、头痛恶心、肌无力。对策：长训练日用运动饮料/电解质片替代部分纯水；抽筋反复出现时优先怀疑电解质缺失而不是"没喝够水"。心律症状对自由潜水员尤其危险（BO 诱因之一）。

**学员脱水的隐藏主因：怕尿湿衣而不敢喝水（教学提醒）**：
- 真实链条：学员嫌脱湿衣麻烦/不好意思尿在湿衣里 → **刻意少喝水** → 补水不足 → 叠加水面暴晒与湿衣保温 → 脱水甚至中暑/热衰竭
- 憋尿本身也不利：充盈的膀胱影响放松、限制膈肌下降（全呼吸变浅）、分散注意力
- 破除方法（开课第一天就讲清楚）：
  1. 直接告诉学员"**尿在湿衣里是潜水员的日常**"——浸入利尿让每个人下水十来分钟就想尿，这是生理反应不是尴尬事
  2. 尿液会被流动水冲淡、课后淡水冲洗湿衣即可，卫生上无碍
  3. 规划饮水节奏：下水前 20-30 分钟最后一次排尿 + 之后小口补水——**不能因为怕尿而牺牲补水**
  4. 长训练日安排中途上船/上岸休息窗口，给学员"正经上厕所"的机会，心理上更容易接受全程补水

**补水实践**：
- 长训练日和冲 PB 日**全程小口规律补水**（W2 教材原文），不要等口渴才喝（口渴出现时已处于缺水状态）
- 从潜水前夜开始补水，而非当天早上临时灌
- DCS 急救时：平卧休息 + 补水约 1L（不给食物）；BO 恢复期：多喝水 + 营养食物（两本教材一致要求）
- 避免酒精和过量咖啡因——都是利尿剂，边喝边漏

### 6.7 专题：低碳酸血症 vs 高碳酸血症，及 packing / 反向填积的危害

**一句话对比**：高 CO₂ 是"警报器在响"——难受但保护你；低 CO₂ 是"拆掉警报器"——舒服但致命。

**低碳酸血症（超呼吸的真正恶果）**：
- 定义：血 CO₂ 低于正常，由超呼吸/过度换气造成
- 危害链条四条：①呼吸欲望被延迟 → **无预警浅水黑视**（最核心）；②脑血管收缩 → 脑血流减少 → 人在水面就可能晕；③波尔效应反向——血偏碱 → 血红蛋白抱氧更紧 → 组织拿不到氧；④抑制 MDR
- 症状：欣快感、末梢刺痛、轻飘飘、头晕、嘴角麻木、口中金属味、手半瘫痪——出现任一即已超呼吸，立即恢复放松呼吸至症状消失
- 关键认知：超呼吸**不会多储一克氧**，只是提前排光了警报器的电池

**高碳酸血症（闭气的正常状态，安全盟友）**：
- 定义：血 CO₂ 高于正常——每次闭气必然发生，**在休闲范围内不是疾病状态**
- 它同时做两件事：①发警报——呼吸欲望、灼热感、横膈膜抽动，越来越强但不危险；②帮你闭气——CO₂ 升高 → 波尔效应正向 → 血红蛋白放氧更痛快（W2 教材原话："也是 CO₂ 使你可以屏住呼吸更长的时间"）
- 初学者把它当敌人（焦虑的主要来源），实际它是唯一可靠的安保系统：**O₂ 缺乏没有体感，CO₂ 堆积全是体感**
- CO₂ 耐受可训练（数周提升、停训退化快）——Base 训练 CO₂ 表的意义所在
- 边界：只有极端高碳酸血症（远超休闲范围）才本身有害；休闲潜水里你一定先受不了去呼吸

**packing（肺部填积）为什么会"入水就 BO"**：
- 机制（已有研究证实）：pack 把肺打到 TLC 以上 → 胸内压骤升 → 压迫腔静脉和心脏 → 静脉回流与心输出量骤降 → 血压骤降（晕厥者平均动脉压实测可跌至约 70 mmHg）→ 脑灌注不足 → **packing 后数秒内即可晕厥**——人还在水面或刚入水，根本没开始下潜
- 晕厥分两型：血管抑制型（外周血管扩张）与心脏抑制型（心动过缓），可混合出现
- 叠加因素：packing 的反复吞气同时排走 CO₂ → 低碳酸脑血管收缩，雪上加霜；**站立位 packing 最危险**（重力+血液坠积下肢）
- 这就是为什么：竞技选手 packing 时坐/躺、pack 完立即入水绝不停留、必须有潜伴全程盯护——且 packing 属 W3 技术，须教练指导
- **满肺拉伸同样可致晕厥**：吸满气（尤其 pack 后）做扩胸/肋间/体侧拉伸 → 胸内压进一步升高 + 体位改变（弯腰、起身）+ 可能的血管迷走反射 → 静脉回流骤减 → 晕厥。规矩同 packing：拉伸坐/靠墙做、不闭气站立拉伸、动作结束缓慢起身、有人陪同

**packing 的完整危害清单**：
1. 水面晕厥（"pack 完就倒"，如上）
2. 肺过度扩张伤：超出 TLC 的气量使肺泡处于极限张力 → 咳嗽、用力、入水冲击即可致肺泡破裂 → 气胸、纵隔气肿、动脉气体栓塞（AGE，已有案例报告）。**口诀：肺泡一破，气走三条路——进胸腔是气胸、钻纵隔是气肿、入血管是 AGE**（三种结局，一次破裂。AGE 的本质是"气体入动脉"这个终点，任何原因的肺泡-毛细血管屏障破裂都能导致——水肺闭气上升、packing 超扩、DCS 肺撕裂殊途同归，并非减压病专属）
3. 心律失常风险（胸内压剧烈波动）
4. 教材红线：W2 明令禁用；竞技也需至少 3 年经验或 60m+ 深度，W3 才正式引入
5. 性价比对照（实测计算）：packing +1L → 深度仅 +6.6m，代价是水面+上升末双重风险；横膈膜/肋间肌拉伸让 RV 降 5% → 深度 +10m 且无急性风险——**拉伸的性价比完胜 packing**

**reverse packing（反向填积）的危害**：
- 机制回顾：关声门后用喉部把肺内空气"抽"入口腔，为深度平压补充气源（W2 教学内容）
- 危害：①气道/胸内形成负压 → 肺毛细血管跨壁压骤增 → **肺水肿/肺出血**风险（强力蛮做时，机制见 6.8"肺水肿的原因"）；②负压可传至咽鼓管 → 中耳负压、鼓膜内陷，极端情况牵拉圆窗；③眩晕、喉部不适、耳闷
- 教材安全要求：**严禁腹肌/呼吸肌辅助**（腹部必须纹丝不动）、放松轻做、避免响亮喉音、陆地循序渐进
- 定位：与 packing 一样是"工具"不是"技巧表演"——按需做、轻做、学会再练

### 6.8 专题：气压伤全类型、轻重分级与症状鉴别

**气压伤分级总表（按部位）**：

| 部位 | 轻度 | 中度 | 重度 |
|---|---|---|---|
| 中耳 | 鼓膜发红、耳堵感（2 周内愈） | 充血剧痛、耳内积液感、听力下降（2 周-2 月） | **鼓膜破裂**（详见下） |
| 外耳（头套挤压） | 耳道皮肤发红、淤血 | 耳道点状出血 | 鼓膜外向撕裂（罕见） |
| 鼻窦 | 压力感、轻痛 | 剧痛 + 鲜红鼻血 | 深部剧痛、大出血 |
| 内耳 | 一过性眩晕 | 持续眩晕、耳鸣 | **永久性听力/前庭损伤** |
| 面镜 | 眼周发红、眼白血丝 | 眼周紫癜、毛细血管破裂 | 眼球损伤（罕见） |
| 肺 | 一过性胸口发紧 | 持续胸痛、咳血丝 | **粉红泡沫痰、呼吸窘迫、AGE——可致命** |

**中耳气压伤三度详解（W1/W2 教材）**：
- **轻微**：鼓膜发红并向内弯曲、耳堵感——停止潜水保持干燥，2 周内自愈
- **中等**：中耳周围组织充血、严重疼痛、"耳朵很涨"、中耳充水感、听力被压抑——保持干燥、避免飞行等压力变化，2 周-2 月恢复
- **严重（鼓膜穿孔/破裂）**：剧烈疼痛→**疼痛突然减轻是陷阱不是好转**（破裂瞬间压差释放、疼痛骤减）→ 眩晕、失去方向感（水进中耳刺激内耳）、外耳道出血/出水、暂时失聪、感染高风险——立即升水停潜、患耳保持干燥、**禁用含酒精滴耳液**、迅速就医
- **实战早期信号**：平压越来越费劲（气难压进去）、每次平压有"吱吱"声（耳咽管周围黏液）= 中耳气压伤正在发生，此时该做的是上浮休息，不是加大力气
- **出水次日鉴别（实战经验）**："耳朵里有水"的感觉 = 两种可能：①耳垢困水在外耳（医生清洁即可，非气压伤）②中耳积液（= 中度气压伤，需就医）
- **中耳积液→中耳炎的升级预警**：积液是细菌的培养基——**次日复查看趋势**：症状无减缓、疼痛不减反增、出现发热或搏动性耳痛 = 继发中耳炎的信号，**须及时就医抗感染消炎**，切勿自行滴药硬扛；期间保持患耳干燥、严禁继续潜水

**头套挤压伤（外耳型，方向相反的气压伤）**：
- 成因：头套过紧或耳垢过多 → 空气困在外耳道 → 下潜时**鼓膜向外弯曲**（与普通中耳气压伤方向完全相反）
- 症状：耳道皮肤发红、淤血、点状出血；严重时鼓膜外凸
- 预防：**下潜前往头套里灌一些水**（排出 trapped air）；耳垢过多者先清耳垢

**鼻窦气压伤与分泌物颜色鉴别（实战精华）**：
- 成因：感冒/过敏/干燥环境致窦口堵塞 → 下潜压差 → 黏膜撕裂
- 症状：额头、颊骨后、鼻梁、上牙剧痛（牙齿剧痛常在入水即刻出现）
- **出水后对着手掌轻呼气检查分泌物颜色**：

| 颜色 | 含义 | 处置 |
|---|---|---|
| 鲜红/血红色 | 黏膜新鲜撕裂 | 停潜，头部**直立不后倾**（防血入咽喉）、冷敷鼻、几天自愈 |
| 深褐色/近黑色 | 陈旧性出血（既往感染或感冒的残留） | 不必立即停潜，可缓慢进行下一潜并观察 |
| 持续清亮水样 | 少见但需警惕深部损伤 | 停潜就医排查 |

- 面镜内见血 = 鼻窦气压伤或鼻出血的同场信号

**肺部气压伤（自由潜挤压伤 PBT，最危险）**：
- 自由潜成因：RV 深度以下过快下潜、身心未放松（血液转移来不及代偿）、深度下剧烈动作、强行平压推气
- 水肺成因：**闭气上升**（气体膨胀无处去）
- 症状五级渐进：①胸口发紧不缓解 → ②呼吸带喘鸣音 → ③几次深呼吸后仍觉呼吸困难 → ④想咳嗽、可咳出**粉红色泡沫痰** → ⑤不消失的疲惫感；重症进展至呼吸窘迫、BO、AGE
- 处理（实战八条）：立即停止一切潜水（**包括戒护和收导潜绳**）→ 忍住不用力咳（防气体入血）→ 轻柔控制呼吸专注放松 → 告知潜伴 → 避免剧烈移动保持低心率 → 有条件吸纯氧 → **立即就医** → 至少休 1 周 + 医生许可再潜
- 预防：自我觉察最关键、只在放松状态潜水、感到压力/感冒/发抖即停、平时拉伸肋间肌和横膈膜、**正确转身技术**（**抬头转身会拉伤喉部、后仰（向后）转身会拉伤肺部**——正确做法：拇指朝上抓绳 + 前滚转身，全程头与身体一线不抬头）、大深度渐进适应诱发血液转移

**喉/气管挤压伤 vs 肺挤压伤——表现差异鉴别（上气道 vs 肺泡）**：
- **机制差异**：肺被压缩到 RV 以下时，喉和气管是半刚性结构、无法跟着压缩 → 上气道内形成**相对负压** → 喉/气管壁血管扩张渗出甚至破裂（上气道挤压伤）；肺挤压则是跨肺毛细血管压力应激 → 非心源性肺水肿 + 肺泡出血（2024 年研究称之为"自由潜诱发肺综合征"）
- **症状鉴别表**：

| 鉴别点 | 喉/气管挤压（上气道） | 肺挤压（肺泡） |
|---|---|---|
| 感觉位置 | 喉咙：痛/灼烧/异物感（"卡了东西"） | 胸部：胸痛/胸闷/肺里有液体感 |
| 声音 | **声音嘶哑（标志性**，出水说话即发现**）** | 无嘶哑 |
| 呼吸 | 基本不影响 | 气短/喘鸣，可严重 |
| 咳嗽与血 | 干咳/清嗓；血呈**鲜红血丝、条索状黏液** | 咳痰（调查中最常见）；咯血呈**泡沫状粉红痰**（血混肺泡水肿液） |
| 全身症状 | 局限，少 | 与潜次不成比例的疲劳；可进展 AGE/气胸 |
| 恢复 | 较快 | 慢（2024 调查：多数约 2 个月才恢复潜水） |

- **转身技术关联（教学）**：抬头转身→颈部过伸→喉部受力拉伤；后仰转身→胸廓过伸→肺组织受力——两类错误转身对应的正是上表两种表现
- **共同红线**：明显咯血、持续呼吸困难/喘鸣、潜水后胸痛 → 立即就医——轻症也可能进行性恶化

**肺水肿的原因（机制统一解释）**——肺水肿的本质是：**肺毛细血管内的压力或通透性超过临界值，液体（和血细胞）越过血管壁漏进肺间质和肺泡**。潜水场景有三条通路：
1. **挤压性（自由潜 PBT 相关）**：深度压缩 → 肺泡体积缩小、肺内压与毛细血管跨壁压差增大 → 肺毛细血管壁应力超限（"肺毛细血管应力衰竭"）→ 血管壁断裂/渗漏 → 液体和红细胞入肺泡（肺水肿 ± 肺泡出血）。肺泡出血时才有粉红泡沫痰——**单纯间质水肿可以完全不咳血**，表现为呼吸困难、喘鸣、持续咳嗽、低氧
2. **浸入性肺水肿（IPE）**：浸没本身 → 静水压把外周血液挤向胸腔（中心血容量↑）+ 冷水引起外周和肺血管收缩 + 水中用力 + 负压吸气（呼吸管/调节器阻力）→ 肺毛细血管压升高 → 液体渗入肺泡。**可发生在水面或浅水**（游泳/浮潜也会），与下潜深度无关；低温、高强度、高血压/心脏病史者风险更高——潜水后呼吸困难但没下过深度时，优先想到 IPE
3. **强负压吸气**：气道受阻或胸腔内骤然形成强负压（如蛮做反向填积、溺水挣扎时用力吸气）→ 跨血管壁压差被"拉"大 → 液体被抽入肺泡
- **共同要点**：咳血/粉红痰只是重度肺泡出血的表现之一，**不是肺水肿的必要症状**——呼吸困难和低氧才是最早、最普遍的信号；处理一律按肺挤压流程（停潜、吸氧、就医）

**易混淆快查（详见 1.7）**：内耳气压伤=强行平压后持续眩晕/耳鸣（就医，可永久损伤）；逆向堵塞=上升时耳痛加剧，**出水后可能眩晕、恶心呕吐**——膨胀气体和压差刺激内耳前庭所致（W2 教材症状列表：眩晕、迷失方向、恶心、呕吐、耳鸣），呕吐时侧头防误吸；变压性眩晕=两耳平压不对称（详见下文详解）。

**差异性眩晕 / 变压性眩晕（Alternobaric Vertigo）详解**：
- 定义：**两耳压力不对称** → 两侧前庭（平衡器官）发出冲突信号 → 大脑收到矛盾信息 → 眩晕。可发生在下降中，**更容易发生在上升时**
- 三大诱因（教材 + 实战）：①一侧咽鼓管开放较少 / 一侧没平压到位 / **单侧逆向堵塞**（上升时两耳减压速度不同步）②两耳温差——冷水单侧灌入（无头套或头套单侧漏水）刺激单侧迷路 ③鼓膜破裂使水单侧流入中耳
- 症状：天旋地转或摇摆感、**不自主眼球震颤**（潜伴肉眼可见眼球来回摆动）、恶心、呕吐、耳鸣、听力低沉、方向感丧失
- 水中处置（七步）：①立即停止移动并**减缓上升**（上升时高发，减速给两耳平衡的时间）→ ②抓牢导潜绳固定身体 → ③**向潜伴示意**出状况（潜伴上前戒护、指明水面方向——眩晕时自己可能分不清哪边是上）→ ④**睁眼注视固定点**（绳结/气泡/潜伴，用视觉代偿前庭冲突）→ ⑤**适当活动下颚和脖子**（开合下颌+左右轻移，帮助咽鼓管开放、促进两耳压力平衡——与逆向堵塞处理同源）→ ⑥温和继续尝试平压 → ⑦等待两耳压力自行平衡（通常数十秒至数分钟消退）——即使消退也结束本次潜水
- 出水后处置：充分休息；眩晕持续不退、或伴听力下降/剧烈呕吐不止 → 警惕内耳气压伤 → **就医并在医生同意 + 充分休息前不再自潜**
- 预防：感冒鼻塞不潜；两耳平压对称充分；头套先灌水（防单侧温差刺激）；**平压较慢的那只耳朵决定下潜速度**
- **教学辨析——逆向堵塞是差异性眩晕的一种吗？** 不是并列关系：逆向堵塞是**病（机械性堵塞）**，差异性眩晕是**症状（前庭信号冲突的表现）**；链条为：单侧逆向堵塞 → 两耳压力不对称 → 前庭信号冲突 → 眩晕。W1 教材明确将逆向堵塞列为眩晕诱因之一；同理，单侧中耳气压伤、单侧耳进冷水也都能触发。反之，**双侧对称**的堵塞因两侧信号对称抵消，反而不引发差异性眩晕

**📌 真实教学案例：温泉冰火浴静态闭气诱发温差性眩晕（2026·广州教练班）**：
- **情境**：46°C/19°C 冷热水交替浸泡数次后，在约 19°C 冷水池做静态闭气（无热身、两口净化呼吸）。1 分多出现持续旋转感；**全程意识清醒**（多次主动睁眼验证、手放池边、对报时 check 反应准确），4:30 出水，出水后继续晕约 5 分钟自愈，无听力下降/耳鸣/呕吐，当晚未饮酒
- **成因（温差版差异性眩晕）**：混合浴存在温度分层——暖水上浮、冷水下沉，面朝下静态时**两只耳朵恰好泡在不同温层**→ 持续不对称温度刺激 → 半规管内淋巴对流 → 壶腹帽偏移 → 大脑把纯温度信号误读为旋转（即临床"冷热试验"原理）；交替浸泡后的外耳道残余温差 + 单侧耳垢隔热进一步加重不对称
- **时间线与机制一一对应**：①1 分多才发作 = 冷量传导到半规管需 30-60 秒（与冷热试验达峰时间一致）；②持续旋转但 check 全对 = 前庭冲突**不影响大脑皮层清醒度**（与缺氧晕厥的本质区别）；③出水后晕约 5 分钟 = 耳温重新平衡需要时间——缺氧性头晕出水几十秒即退，**5 分钟的尾巴是前庭性的"指纹"**
- **叠加因素**（贡献晕、不贡献转）：高温浸泡血管扩张+出汗脱水→低血压倾向；两口净化呼吸→轻度低碳酸脑血管收缩；热水后骤入冷水→MDR 心率摆动
- **五条教学要点**：①水中眩晕的真正风险**不是失去意识而是失去方向感**——若发生在开放水域 10m 处将无法分辨哪边是上；②眩晕一出现就应中止上浮（抓固定物+注视固定点+等待平衡），而不是硬撑到目标时间；③高温池泡完不马上闭气（核心温度+血流波动+脱水三重叠加）；④冷水静态戴头套/保证两耳同温可大幅降低发生率；⑤就医红线 = 眩晕数小时不退、听力下降、耳鸣、呕吐
- **适用场景提醒**：冷水泳池课、冬潜、温泉/水疗池静态、无头套冷水训练

### 6.9 专题：氮醉的原理——为什么高压氮会"醉人"

**一句话机制**：高压下大量氮气溶入**神经细胞的脂质膜**，扰乱膜上的离子通道和突触信号传递 → 神经传导被可逆性抑制——本质上是一种**弱麻醉**。

**四步链条**：
1. 深度 → 环境压力↑ → 肺内与血液中氮分压↑（道尔顿定律）——40m 时总压 5 bar，PN₂ ≈ 5 × 78% ≈ **3.9 bar，约为水面的 4-5 倍**
2. 氮是脂溶性气体，按亨利定律溶入组织，特别是**神经细胞膜**（磷脂双分子层——膜的"骨架"就是脂肪）
3. 溶进膜的氮分子改变膜的厚度与流动性 → 干扰钠离子通道的开闭、神经递质释放、突触间的信号传递
4. 大脑高级功能（判断力、注意力、短时记忆）最先被抑制 → 欣快、反应迟钝、视物波动、声音变远——和醉酒是同一种"被抑制"的体验，所以叫"深海醉"

**Meyer-Overton 法则（麻醉能力 ∝ 脂溶性）**：氮的脂溶性很低，所以要 4-5 bar 的分压才显效（真正的麻醉气体只需零点几 bar）；氦的脂溶性更低 → 几乎不麻醉 → 这就是深潜技术潜水用氦气替代氮的原因之一。

**教学串联——氮的"亲脂肪"一个性质，两个后果**：
- 溶进脂肪组织慢慢囤积 → 上升时析出气泡 → **减压病**（见 6.1：脂肪溶解度约为血液 5 倍）
- 溶进神经细胞膜干扰信号 → **氮醉**
- 换氦气 = 一石二鸟：既减少囤积又避免麻醉

**为什么自由潜比水肺"更耐醉"**：自由潜只带一口氮、暴露时间短，只有快组织来得及吸收 → 触发深度更深（自由潜约 40m+ 可感知、50m+ 明显；水肺持续呼吸压缩空气 >30m 即可发作）。

**为什么上升就"醒酒"**：压力下降 → 膜内氮按分压梯度扩散回血液 → 经肺排出 → 膜功能恢复——**完全可逆**。但注意：深潜出水后仍有"微醺残留"时段，期间不要做再潜决策（竞技报告中有深潜后片段遗忘的案例）。

> Cousteau 给它起了个浪漫的名字："深海的醉意"（rapture of the deep）。
